# 🚀 KSP AI Mod Factory

Uma inteligência artificial autónoma de criação de conteúdo tridimensional para o Kerbal Space Program.

## 🔥 Funcionalidades Supremas
- **Blender Automation:** Gera malhas rígidas (.fbx) através de scripts Python locais.
- **Unity Injetor:** Descarrega e instala o KSP PartTools silenciosamente na pasta de Assets.
- **Limpeza de Emergência:** Fecha o KSP e elimina o `ConfigCache` e o `PartDatabase.cfg` se o ecrã de carregamento congelar.
- **Compatibilidade:** Suporte universal para versões originais (Steam) e alternativas (Hydra / SteamGG).

## 🛠️ Como Usar (Comandos de Voz)
1. Descarrega e corre o `instalador.exe`.
2. Mantém o teu microfone ligado.
3. Diz: *"IA, limpar jogo"* ou *"IA, gerar bomba nuclear"*.
